# Daily State Briefing

A lightweight AI state briefing MVP.

The goal is to test whether users trust and rely on daily AI-generated state explanations and decisions.

## Current Stage

Concierge MVP / Fake AI validation.

## Product Flow

Morning:
User answers 4 questions.
System generates Today Status, Explanation, and Today Decision.

Night:
User answers reflection questions.
System generates Day Summary, Main Drain, and Tomorrow Prep.

## Build Goal

Create a simple local web prototype for 14-day user testing.
